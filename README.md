# Overview

BluCooldown is a lightweight, high-performance Minecraft plugin that adds configurable cooldowns to any item&#x20;

Designed for modern Paper and Folia servers, BluCooldown focuses on performance, simplicity, and compatibility with Minecraft 1.21+

## Features

* Native Minecraft cooldown animation
* Fully configurable item cooldowns
* Supports any item using Bukkit Material names
* Lightweight and optimized
* Folia compatible
* Java 21 support
* Paper 1.21+ support
